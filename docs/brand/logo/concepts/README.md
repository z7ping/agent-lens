# AgentLens Logo 候选方案存档

本目录用于保存 2026-08-25 Logo 设计讨论中的候选方向。

说明：最终采用的第 5 套存在正式 SVG 源，因此 `concept-05-final.svg` 与正式设计源一致；其余候选当时仅作为生成图讨论，没有独立矢量源进入仓库，本目录按当天“极简、轨迹 / 路径”方向重构为 SVG，用于保留设计演进，不宣称与当时位图逐像素一致。

## 主源资格

本目录内 6 份 SVG 均按“可作为品牌主源”的标准维护：

- 纯矢量几何，可无损缩放。
- 自带独立 `viewBox`，不依赖固定像素尺寸。
- 不包含 `<image>`、位图、外链资源、脚本或外部样式。
- 不包含 `<text>`，没有字体安装和字体渲染依赖。
- 渐变、颜色、路径和几何全部自包含在 SVG 内。
- 可以直接作为后续 PNG、ICO、Web 图标、桌面图标等派生资产的输入源。

因此，如果未来重新采用某一候选方案，应直接以对应 `concept-*.svg` 为该方案的矢量主源继续演进，而不是从 PNG 截图或缩略图反向描摹。

需要区分的是：`concept-01/02/03/04/06.svg` 属于**候选重构主源**，不是当时生成位图对应的原始矢量文件；`concept-05-final.svg` 则与最终采用方案的正式 SVG 几何同源。

| 文件 | 方向 | 状态 |
| --- | --- | --- |
| `concept-01.svg` | 单轨迹进入镜头焦点 | 候选重构主源 |
| `concept-02.svg` | 双来源路径汇聚后进入镜头 | 候选重构主源 |
| `concept-03.svg` | 几何字母 / 路径与镜头结合 | 候选重构主源 |
| `concept-04.svg` | 环形观察域 + 穿行轨迹 | 候选重构主源 |
| `concept-05-final.svg` | 双来源节点 → 双轨迹 → 双层镜头焦点 | **最终采用 / 正式同源** |
| `concept-06.svg` | 平行路径汇聚到双层观察镜头 | 候选重构主源 |

当前品牌唯一正式基线仍是父目录的 `agentlens-logo.svg` 和 `agentlens-logo-small.svg`；本目录用于保存可重新启用的候选主源，不被构建流程直接引用。

`npm run check:brand-assets` 会校验这些 SVG 仍保持纯矢量、自包含、无字体和无位图依赖，防止后续编辑把主源退化成不可复用的导出物。
