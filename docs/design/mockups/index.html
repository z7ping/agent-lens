任务复盘

时间分组的会话列表、分区重排的轮次导航、工具耗时占比条、浮动“有新记录”提示、Tab 化 Inspector（详情 / 证据 / 原始数据）。可点击工具行与事件行体验 Inspector。

打开画板 → BOARD 02

四卡 KPI（含归因覆盖率）、可排序表格 + 调用分布条 + 成功率双色条、行钻取抽屉（会话分布 / 错误示例）、带置信度的可归因资产。表头可点击排序。

打开画板 → BOARD 03

智能体概览

字号修正后的资产卡片、比例化技能生命周期漏斗、色块+文字双层编码的跨 Agent 覆盖矩阵。静态发现与真实调用保持分离。

打开画板 → BOARD 04

状态与引导

骨架屏、SSE 断开横幅、页级错误恢复、带行动指引的空状态、首次运行三步引导、后台视图新数据提示。
