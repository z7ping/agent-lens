v2.1 当前约束
  • 信息架构：任务复盘 / 工具分析 / 使用洞察 / 智能体概览 / 资产备份五个页面顶部直达。
  • 证据可见：Evidence（证据）默认可见；原始记录与审计细节按需展开。
  • 长会话：最近轮与错误轮默认展开，turn-rail 定位，round-nav 筛选。
  • 真实口径：发现 ≠ 使用，未知 ≠ 0；缺失事实不通过演示数据补齐。
  • 表现：正常文字下限 12px；高信息密度但降低视觉噪音，正常态中性，异常才使用强语义色。
