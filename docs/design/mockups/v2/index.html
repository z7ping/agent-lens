AgentLens 当前高保真原型

这是正式程序适配前的唯一高保真基线。任务复盘采用“对话主线 + 执行轨迹证据”，其他一级页面直接进入关键数据，不再重复导航已经表达的页名与长篇介绍。

v2.1 当前约束
  • 信息架构：任务复盘 / 工具分析 / 使用洞察 / 智能体概览 / 资产备份五个页面顶部直达；一级导航已选中时正文不重复页名。
  • 背景层级：冷中性灰画布承托白色数据层；任务复盘左侧浅灰、右侧阅读区白色。
  • 证据可见：证据（Evidence）默认可见；原始记录与审计细节按需展开。
  • 任务复盘：对话是主线，执行轨迹是证据；用户右侧、智能体左侧，生命周期 / 可观察过程片段 / 工具 / 事件穿插展示。
  • 长会话：最近轮与错误轮优先展开，轮次轨（turn-rail）定位，轮次筛选（round-nav）过滤；左侧会话列表滚动到底部自动加载下一批。
  • 真实口径：发现 ≠ 使用，未知 ≠ 0；缺失事实不通过演示数据补齐。
  • 表现：正常文字下限 12px；高信息密度但降低视觉噪音，正常态中性，异常才使用强语义色。
