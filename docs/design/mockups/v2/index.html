UI / UX DESIGN PROPOSAL · V2.1

AgentLens 高保真静态稿 · v2.1

以产品定位重新收敛 v2：五个页面顶部直达，只用顺序、留白和分隔表达任务、使用、资产的关联；保留真实会话列表与证据可见性；长会话采用智能折叠；资产备份和使用洞察按现有实现同步。明暗主题跨页记忆。

v2.1 关键融合决策
  • 降噪基调：KPI 成细线长条、徽章透明底、正常态中性色、分区靠细线不靠卡片堆叠；异常才用强语义色。
  • 信息架构：任务复盘 / 工具分析 / 使用洞察 / 智能体概览 / 资产备份五个页面顶部直达；只用留白与细分隔表达关联，不增加分类层。
  • 证据可见性：Evidence 徽章默认可见但安静；「显示原始记录」只补充权限、生命周期、后台活动与原始载荷，不把证据本身藏起来。
  • 轮次呈现：最近轮与错误轮默认展开，其余轮保留标题锚点；支持展开当前页。turn-rail 负责定位，round-nav 负责筛选。
  • 会话列表：保留卡片化（描边减淡），修复“条目区分不明显”；按项目聚合作为切换项出现在面板头（P1 讨论项）。
  • 消息布局：用户使用高对比深色气泡，智能体内容左侧限宽；来源记录中的 reasoning 命名为「可观察过程片段」，不暗示隐藏思维。
  • 字号下限：统一 11px（修正 balanced 稿 10.5px 徽章与其自身 12px 规范的矛盾）。
  • 真实数据口径：缺失耗时显示为未观察到；洞察先展示统计范围与样本覆盖；智能体采用来源列表 + 单一详情，避免资产很多时巨卡并排。
