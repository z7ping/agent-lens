UI / UX DESIGN PROPOSAL · V2 融合版

AgentLens 高保真静态稿 · v2

融合两套设计：以「轻度降噪」为视觉基调，保留证据可见性与全量状态覆盖；吸收 turn-rail、KPI 细线长条、审计视图开关、SVG 图标集；收编资产备份与使用洞察两个长期能力原型。明暗主题跨页记忆。

v2 关键融合决策
  • 降噪基调：KPI 成细线长条、徽章透明底、正常态中性色、分区靠细线不靠卡片堆叠；异常才用强语义色。
  • 证据可见性：Evidence 徽章默认可见但安静；右上角「显示审计细节」开关（记忆偏好）补全权限事件、生命周期原始事件、后台活动轮与证据说明——阅读流与审计流分层，但证据不默认隐藏。
  • 轮次呈现：连续流式 + 恒展开（标题为锚点）；左缘 turn-rail 只负责定位，「全部/有错误/耗时较高」筛选保留在 round-nav，二者分工明确。
  • 会话列表：保留卡片化（描边减淡），修复“条目区分不明显”；按项目聚合作为切换项出现在面板头（P1 讨论项）。
  • 消息布局：用户气泡右对齐、智能体内容左侧限宽（ChatGPT / Codex 习惯）；工具图标统一内联 SVG。
  • 字号下限：统一 11px（修正 balanced 稿 10.5px 徽章与其自身 12px 规范的矛盾）。
  • 长期能力：资产备份 / 使用洞察整页收编，标注「长期能力原型」，不属于 1.0 承诺范围。
