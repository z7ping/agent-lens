设计系统

把这轮轻度降噪固化成可复用规则：信息基本保留，主次通过字号、留白、边线和小面积语义色区分，不依赖“大卡片 + 大底色 + 多徽章”。

视觉层级

同一屏的信息分成三层；第三层可以展开，但不是默认消失。

第一层 · 决策信息标题、核心数字、会话内容、工具名、错误
第二层 · 解释信息时间、来源、调用次数、路径摘要、状态
第三层 · 审计信息Evidence、完整路径、Hash、原始事件、内部状态

颜色使用

来源色和工具类型色只用于小面积识别；异常才允许扩大视觉权重。

画布表面弱表面强调成功警告错误
规则来源色用于点 / 细描边；工具语义色用于图标徽章；正常状态避免整卡染色。

工具类型徽章

图标表达“是什么工具”，错误表达“执行结果”；两者不能混成同一个图标。

容器与留白

能用标题 + 留白 + 分隔线表达分组，就不再新增一层卡片。

一个独立区块

标题与说明建立层级，内容只在确实需要边界时使用一层面板。

这是可交互 / 可滚动 / 独立对象，因此保留一层容器；内部不再继续套卡片。
