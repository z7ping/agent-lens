## 对齐原则

正式 Web 以 v2.1 当前稿的布局、信息层级、交互密度、字号、间距和状态表达为表现层基线，但不能为了像原型而牺牲事实真实性。

当正式能力比静态稿更完整时，以真实产品语义为准，并同步更新原型。例如：

- 智能体必须区分“已检测”和“已启用采集”；
- 可观测能力展示采集方式和不完整原因；
- 工具错误示例如果当前接口没有逐次错误载荷，不使用演示文本冒充真实错误；
- 未报告的生命周期状态保持“未报告 / —”，不能按 0 展示；
- 健康接口没有端口字段时，顶部状态不得硬编码端口；
- Hook 属于具体 Source 的采集实现，不单独作为首次运行产品步骤；
- 未实现的 P1/P2 控件不进入当前 1.0 原型。

## 当前正式 Web 已收口

- 五个一级页面直达；
- Header 使用正式 AgentLens Logo，主题切换使用 SVG 图标；
- 顶部状态统一表达后台服务、存储和实时通道，异常状态不伪造端口；
- 正常界面文字下限统一为 12px；
- 窄窗口下品牌、导航与状态区可压缩，不共用页面滚动；
- 任务复盘左右独立滚动、时间分组、智能折叠、轮次导航；
- 用户消息右侧、智能体消息左侧；
- Evidence（证据）默认可见；
- “显示原始记录”仅补充来源原始事件与载荷；
- 复盘检查器“详情 / 证据 / 原始数据”三页签；
- 搜索防抖和筛选地址状态化；
- 工具类型统一使用 SVG 图标；
- 工具分析真实会话钻取、Top 3 会话分布、“需要关注”和能力资产比例条；
- 智能体来源列表 + 单一详情、真实采集启用状态、能力采集说明；
- 高频资产真实比例条、技能生命周期真实比例漏斗；
- 首次运行引导按“检测来源 → 启用采集并确认运行 → 产生可复盘会话”表达；
- 使用洞察与资产备份原型已反向同步当前真实能力边界；
- v2.1 最终对齐样式由 `packages/web/src/v2-alignment.css` 最后加载。
