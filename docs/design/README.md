截至当前：

- 工具分析、使用洞察、智能体概览、资产备份已经去掉与一级导航重复的可见页标题和常驻介绍段。
- 全部 v2 原型共用冷中性背景色板。
- 正式 `packages/web/src/tokens.css` 已与当前原型基础色板重新一致；浅色次要文字同时完成 4.5:1 对比度修正。
- 正式“全部智能体 +”已改为页面根层固定定位弹层，不再受工具栏裁切。
- 正式任务复盘左侧会话列表已由手动加载改为接近底部自动分页，并保留点击重试入口。
- 任务复盘现有 Evidence（证据）、源码、原始数据、工具详情、生命周期、Pi 会话树、长会话分页、虚拟挂载和实时数据能力继续保留。
- 用户可见文案默认中文优先；来源产品名、路径、命令和原始字段保留原文。
- 正式 Web 其余页面仍在继续做视觉 / 交互适配，因此当前不能宣称“程序与原型完全一致”。

## 3. 当前色彩基线

浅色原型使用冷中性层级：

- 页面画布：`#F5F7FA`
- 白色数据层：`#FFFFFF`
- 次级区域：`#EEF2F6`
- 分割线：`#E1E6EC`
- 强分割线：`#D5DBE3`
- 次要文字：`#646F82`（在次级区域上满足正常文字 4.5:1 对比度门禁）

使用原则：

- 工具栏、卡片、表格、抽屉：白色数据层；
- 一级分析页外层：冷灰画布；
- 任务复盘左侧会话列表：浅灰层级；
- 任务复盘右侧阅读区：白色；
- 不使用毛玻璃背景。

`packages/web/src/tokens.css` 与 `docs/design/mockups/v2/assets/tokens.css` 的基础色值必须继续保持一致。不能通过放宽 `check:web-presentation` 规则来掩盖原型 / 正式程序差异。

## 4. 一级页面规则

顶部固定五个一级入口：

1. 任务复盘
2. 工具分析
3. 使用洞察
4. 智能体概览
5. 资产备份

一级导航已经有选中态，因此正文不再重复显示当前一级页名。任务复盘中的当前会话标题属于数据内容，继续显示。

正常文字下限 12px。主要层级：正文 14px，列表 / 表格主体 13px，辅助信息 12px。22px 用于当前会话标题和设计系统等非一级业务页标题。

## 5. 任务复盘基线

任务复盘的定义：**对话是主线，执行轨迹是证据。**

当前关键规则：

- 左侧会话列表约 320px，右侧阅读内容最大宽度约 1320px。
- 左右独立滚动。
- 会话按今天 / 昨天 / 更早分组。
- 左侧存在更多会话时，滚轮或滚动条到底部自动加载下一批，每批最多 40 条，并显示明确提示。
- 用户消息右侧，智能体消息左侧。
- 轮次使用横向分隔，不恢复大面积轮次卡片。
- 生命周期使用紧凑单排：图标、中文事件、简短说明、证据、来源、时间。
- 可观察过程片段使用弱强调色块，不使用普通回复的视觉层级。
- 工具执行使用紧凑折叠组和 SVG 类型图标。
- 证据（Evidence）默认可见。
- 用户、智能体、可观察过程片段保留证据详情和源码查看能力。
- 工具详情保留输入、命令 / 路径 / 查询、输出 / 错误、证据和原始数据。
- 原始记录开关只增加原始信息，不隐藏默认证据。
- 长会话保留轮次轨、筛选、加载更早轮次、增量数据、错误重试和跟随最新状态。
- 后台活动与普通用户轮次分开表达。

静态原型只演示交互语义，不能用演示实现替代正式服务端分页、虚拟挂载和实时数据逻辑。

## 6. 其他一级页面基线

### 工具分析

- 首屏直接进入关键指标和工具表格。
- 指标：最高频、失败最多、平均最慢、可靠归因覆盖。
- 工具表格可排序，点击进入详情。
- 不伪造接口没有提供的逐次错误载荷。

### 使用洞察

- 首屏直接进入统计范围和核心指标。
- 核心指标：会话、交互、工具调用、明确失败。
- 继续保留趋势、周期变化、智能体使用结构、资产采用和重复工作流模式。
- 发现与使用、共同出现与因果关系必须严格区分。

### 智能体概览

- 左侧完整来源列表，右侧单一智能体详情。
- 五来源：Claude Code / Codex / Pi / Hermes / OpenCode。
- 检测状态与采集状态分开表达。
- 高频资产矩阵中的“未观察到”不等于不存在。
- 顶部快捷来源与左侧完整来源列表目前职责不同，程序适配时不要自行删减。

### 资产备份

- 已属于 1.0 当前能力，不再作为“未来原型”管理。
- 保护技能、模型上下文协议（MCP）、插件、扩展、钩子、记忆、规则、会话 / 历史、关键配置、其他。
- 凭据、令牌、私钥等敏感内容默认排除。
- 当前只开放恢复预演，不直接写回原智能体目录。

## 7. 正式程序适配进度

当前按以下顺序收敛：

1. **全局令牌 / 壳层：进行中。** 基础色板已同步；次要文字对比度门禁已修正；快捷智能体弹层已结构性解决裁切问题；后续继续检查壳层字号、响应式和剩余字符图标。
2. **任务复盘：进行中。** 左侧会话已接入接近底部自动分页；正式 Evidence、详情、分页、虚拟挂载、实时数据、Pi 会话树等能力全部保留；下一步继续对齐 `review.html` 的视觉层级与生命周期单排表达。
3. **其他一级页面：待继续。** 按工具分析 → 使用洞察 → 智能体概览 → 资产备份逐页核对，不删除正式数据能力。
4. **统一验证：待适配收口后完成。** 运行 `check:web-presentation`、类型检查、测试和完整构建，并以真实页面验收结果继续修正。

高保真原型只作为视觉 / 交互基线，不复制原型 HTML 重写 React；任何 1:1 对齐都不得以删除正式能力为代价。
