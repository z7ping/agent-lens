## 1. 当前阶段

当前阶段不再扩展新的 P1 / P2 功能，也不重新设计已经确定的 1.0 架构。设计侧目标是先把当前高保真基线收敛到无明显自相矛盾，再进入正式 React / CSS 程序适配。

截至当前：

- `review.html` 已正式采用执行轨迹方案，不存在并列的 trajectory / history 版本；旧方案只通过 Git 历史查看。
- 工具分析、使用洞察、智能体概览、资产备份已经去掉与一级导航重复的可见页标题和常驻介绍段。
- 全部 v2 原型共用冷中性背景色板。
- “全部智能体 +”的菜单层级由共享原型层统一处理，不允许被工具栏裁切。
- 用户可见文案默认中文优先；来源产品名、路径、命令和原始字段保留原文。
- 正式 Web 仍有一部分表现层等待下一步程序适配，因此当前不能再宣称“程序与原型完全一致”。

## 3. 当前色彩基线

浅色原型使用冷中性层级：

- 页面画布：`#F5F7FA`
- 白色数据层：`#FFFFFF`
- 次级区域：`#EEF2F6`
- 分割线：`#E1E6EC`
- 强分割线：`#D5DBE3`

使用原则：

- 工具栏、卡片、表格、抽屉：白色数据层；
- 一级分析页外层：冷灰画布；
- 任务复盘左侧会话列表：浅灰层级；
- 任务复盘右侧阅读区：白色；
- 不使用毛玻璃背景。

当前 `packages/web/src/tokens.css` 仍保留上一轮正式色值。这个差异是**下一步程序适配的明确待办**，不是设计侧需要继续保留的双重标准。

## 4. 一级页面规则

顶部固定五个一级入口：

1. 任务复盘
2. 工具分析
3. 使用洞察
4. 智能体概览
5. 资产备份

一级导航已经有选中态，因此正文不再重复显示当前一级页名。任务复盘中的当前会话标题属于数据内容，继续显示。

正常文字下限 12px。主要层级：正文 14px，列表 / 表格主体 13px，辅助信息 12px。22px 用于当前会话标题和设计系统等非一级业务页标题。

## 5. 任务复盘基线

任务复盘的定义：**对话是主线，执行轨迹是证据。**

当前关键规则：

- 左侧会话列表约 320px，右侧阅读内容最大宽度约 1320px。
- 左右独立滚动。
- 会话按今天 / 昨天 / 更早分组。
- 左侧存在更多会话时，滚轮或滚动条到底部自动加载下一批，每批最多 40 条，并显示明确提示。
- 用户消息右侧，智能体消息左侧。
- 轮次使用横向分隔，不恢复大面积轮次卡片。
- 生命周期使用紧凑单排：图标、中文事件、简短说明、证据、来源、时间。
- 可观察过程片段使用弱强调色块，不使用普通回复的视觉层级。
- 工具执行使用紧凑折叠组和 SVG 类型图标。
- 证据（Evidence）默认可见。
- 用户、智能体、可观察过程片段保留证据详情和源码查看能力。
- 工具详情保留输入、命令 / 路径 / 查询、输出 / 错误、证据和原始数据。
- 原始记录开关只增加原始信息，不隐藏默认证据。
- 长会话保留轮次轨、筛选、加载更早轮次、增量数据、错误重试和跟随最新状态。
- 后台活动与普通用户轮次分开表达。

静态原型只演示交互语义，不能用演示实现替代正式服务端分页、虚拟挂载和实时数据逻辑。

## 6. 其他一级页面基线

### 工具分析

- 首屏直接进入关键指标和工具表格。
- 指标：最高频、失败最多、平均最慢、可靠归因覆盖。
- 工具表格可排序，点击进入详情。
- 不伪造接口没有提供的逐次错误载荷。

### 使用洞察

- 首屏直接进入统计范围和核心指标。
- 核心指标：会话、交互、工具调用、明确失败。
- 继续保留趋势、周期变化、智能体使用结构、资产采用和重复工作流模式。
- 发现与使用、共同出现与因果关系必须严格区分。

### 智能体概览

- 左侧完整来源列表，右侧单一智能体详情。
- 五来源：Claude Code / Codex / Pi / Hermes / OpenCode。
- 检测状态与采集状态分开表达。
- 高频资产矩阵中的“未观察到”不等于不存在。
- 顶部快捷来源与左侧完整来源列表目前职责不同，程序适配时不要自行删减。

### 资产备份

- 已属于 1.0 当前能力，不再作为“未来原型”管理。
- 保护技能、模型上下文协议（MCP）、插件、扩展、钩子、记忆、规则、会话 / 历史、关键配置、其他。
- 凭据、令牌、私钥等敏感内容默认排除。
- 当前只开放恢复预演，不直接写回原智能体目录。

## 7. 程序适配前的边界

设计侧确认后，下一步正式程序适配需要重点收敛：

1. 正式 `packages/web/src/tokens.css` 与当前原型色板重新一致；
2. 一级页面重复标题与首屏占用按当前规范同步；
3. 任务复盘按 `review.html` 收敛视觉层级，但不得删除正式 `ReviewPage` 已有证据、详情、分页、虚拟挂载、实时数据等能力；
4. 左侧会话列表由手动“加载更多”改成接近底部自动分页，并保留加载 / 错误 / 已全部加载状态；
5. “全部智能体 +”在正式 Web 使用结构性非裁切弹层，不依赖单页层级补丁；
6. 程序适配结束后重新跑 `check:web-presentation`、类型检查、测试和构建。

目前设计令牌已经先于正式运行时变化，因此表现收敛检查会因为原型 / 正式令牌不一致而失败。**不要通过放宽检查规则绕过；下一步程序适配应消除这个差异。**
