## 1. 当前阶段

当前阶段不再扩展新的 P1 / P2 功能，也不重新设计已经确定的 1.0 架构。设计基线保持基本冻结，正式程序按“保留真实数据和运行时能力，只迁移已确认视觉 / 交互”的原则逐步适配。

截至当前：

- `review.html` 已正式采用执行轨迹方案，不存在并列的 trajectory / history 版本；旧方案只通过 Git 历史查看。
- 工具分析、使用洞察、智能体概览、资产备份已经去掉与一级导航重复的可见页标题和常驻介绍段。
- 全部 v2 原型共用冷中性背景色板。
- 正式 `packages/web/src/tokens.css` 已与当前原型基础色板重新一致；浅色次要文字同时完成 4.5:1 对比度修正。
- 正式“全部智能体 +”已改为页面根层固定定位弹层，不再受工具栏裁切。
- 正式任务复盘左侧会话列表已由手动加载改为接近底部自动分页，并保留点击重试入口。
- 任务复盘现有证据（Evidence）、源码、原始数据、工具详情、生命周期、Pi 会话树、长会话分页、虚拟挂载和实时数据能力继续保留。
- `review.css` 已成为任务复盘唯一正式视觉所有者；`review-reference.css`、`review-message-actions.css` 已删除，`review-long-session.css` 只保留长会话性能、独立滚动与轮次轨职责。
- 全局壳层已建立正式 `shell.css`；共享语义色改由 `semantic-colors.css` 提供，历史 `color-system.css` 已删除。
- 工具分析、使用洞察、智能体概览、资产备份已经分别由 `tools.css`、`insights.css`、`agents.css`、`backup.css` 正式接管。
- `v2-alignment.css`、`p0-polish.css`、`prototype.css` 已完成迁空并删除，不能再作为新的覆盖层恢复。
- `styles.css` 已收缩为 Tailwind 语义映射、浏览器基础规则、通用空状态与 Markdown，不再承载壳层、工具分析或智能体概览页面样式。
- 资产备份历史压缩样式已整理，正常可见文字统一到不低于 12px；保护卡片不再通过整体透明度降低可读性。
- 使用洞察已移除越权的顶部品牌隐藏规则，壳层响应式继续由 `shell.css` / `shell-responsive.css` 负责。
- 用户可见文案默认中文优先；来源产品名、路径、命令和原始字段保留原文。
- 正式 Web 仍需完成真实程序逐页验收，因此当前不能宣称“程序与原型完全一致”。

## 3. 当前色彩基线

浅色原型使用冷中性层级：

- 页面画布：`#F5F7FA`
- 白色数据层：`#FFFFFF`
- 次级区域：`#EEF2F6`
- 分割线：`#E1E6EC`
- 强分割线：`#D5DBE3`
- 次要文字：`#646F82`（在次级区域上满足正常文字 4.5:1 对比度门禁）

使用原则：

- 工具栏、卡片、表格、抽屉：白色数据层；
- 一级分析页外层：冷灰画布；
- 任务复盘左侧会话列表：浅灰层级；
- 任务复盘右侧阅读区：白色；
- 不使用毛玻璃背景。

`packages/web/src/tokens.css` 与 `docs/design/mockups/v2/assets/tokens.css` 的基础色值必须继续保持一致。不能通过放宽 `check:web-presentation` 规则来掩盖原型 / 正式程序差异。

## 4. 一级页面规则

顶部固定五个一级入口：

1. 任务复盘
2. 工具分析
3. 使用洞察
4. 智能体概览
5. 资产备份

一级导航已经有选中态，因此正文不再重复显示当前一级页名。任务复盘中的当前会话标题属于数据内容，继续显示。

正常文字下限 12px。主要层级：正文 14px，列表 / 表格主体 13px，辅助信息 12px。22px 用于当前会话标题和设计系统等非一级业务页标题。

## 5. 任务复盘基线

任务复盘的定义：**对话是主线，执行轨迹是证据。**

当前关键规则：

- 左侧会话列表约 320px，右侧阅读内容最大宽度约 1320px。
- 左右独立滚动。
- 会话按今天 / 昨天 / 更早分组。
- 左侧存在更多会话时，滚轮或滚动条到底部自动加载下一批，每批最多 40 条，并显示明确提示。
- 用户消息右侧，智能体消息左侧。
- 轮次使用横向分隔，不恢复大面积轮次卡片。
- 生命周期使用紧凑单排：SVG 图标、中文事件、简短说明、证据、来源、时间。
- 可观察过程片段使用弱强调色块，不使用普通回复的视觉层级。
- 工具执行使用紧凑折叠组和 SVG 类型图标。
- 证据（Evidence）默认可见。
- 用户、智能体、可观察过程片段保留证据详情和源码查看能力。
- 工具详情保留输入、命令 / 路径 / 查询、输出 / 错误、证据和原始数据。
- 原始记录开关只增加原始信息，不隐藏默认证据。
- 长会话保留轮次轨、筛选、加载更早轮次、增量数据、错误重试和跟随最新状态。
- 后台活动与普通用户轮次分开表达。

静态原型只演示交互语义，不能用演示实现替代正式服务端分页、虚拟挂载和实时数据逻辑。

## 6. 其他一级页面基线

### 工具分析

- 首屏直接进入关键指标和工具表格。
- 指标：最高频、失败最多、平均最慢、可靠归因覆盖。
- 工具表格可排序，点击进入详情。
- 不伪造接口没有提供的逐次错误载荷。

### 使用洞察

- 首屏直接进入统计范围和核心指标。
- 核心指标：会话、交互、工具调用、明确失败。
- 继续保留趋势、周期变化、智能体使用结构、资产采用和重复工作流模式。
- 发现与使用、共同出现与因果关系必须严格区分。

### 智能体概览

- 左侧完整来源列表，右侧单一智能体详情。
- 五来源：Claude Code / Codex / Pi / Hermes / OpenCode。
- 检测状态与采集状态分开表达。
- 高频资产矩阵中的“未观察到”不等于不存在。
- 顶部快捷来源与左侧完整来源列表目前职责不同，程序适配时不要自行删减。

### 资产备份

- 已属于 1.0 当前能力，不再作为“未来原型”管理。
- 保护技能、模型上下文协议（MCP）、插件、扩展、钩子、记忆、规则、会话 / 历史、关键配置、其他。
- 凭据、令牌、私钥等敏感内容默认排除。
- 当前只开放恢复预演，不直接写回原智能体目录。

3. **其他一级页面：结构收敛完成，进入真实页面验收。** 工具分析、使用洞察、智能体概览、资产备份均已有正式页面样式所有者；阶段覆盖层与旧原型落地层已全部退役。
4. **统一验证：进行中。** `check:web-presentation` 已改为检查“样式所有者”而非“最后加载覆盖”；继续完成三平台类型检查、测试、完整构建，并根据真实程序逐页视觉验收做最后修正。

## 8. 正式 CSS 维护边界

正式程序不再新增 `final`、`alignment`、`polish`、`override`、`prototype` 一类“最后加载覆盖前面规则”的补丁式样式层。

正式职责固定为：

- 全局基础：`styles.css`，只保留 Tailwind 映射、浏览器基础、通用状态与 Markdown；
- 设计令牌：`tokens.css`；
- 共享语义配色：`semantic-colors.css`；
- 全局壳层：`shell.css`；响应式壳层规则由 `shell-responsive.css` 承担；
- 任务复盘视觉：`review.css`；长会话性能 / 独立滚动 / 轮次轨：`review-long-session.css`；
- 工具分析：`tools.css`；
- 使用洞察：`insights.css`；
- 智能体概览：`agents.css`；
- 资产备份：`backup.css`；
- 共用 SVG：正式图标组件，不为单个覆盖规则建立临时最终层。

`v2-alignment.css`、`p0-polish.css`、`prototype.css`、`color-system.css`、`review-reference.css`、`review-message-actions.css` 等历史覆盖层均已退役，不能重新创建。页面样式不得越权修改全局 Header / 导航；全局壳层也不得重新承载单页视觉规则。

CI 的 `check:web-presentation` 继续锁定：正式所有者文件不得依赖 `!important` 争夺优先级；已退役覆盖层不得重新创建；正常文字不低于 12px；设计令牌、关键交互、响应式和对比度契约必须继续满足。

高保真原型只作为视觉 / 交互基线，不复制原型 HTML 重写 React；任何 1:1 对齐都不得以删除正式能力为代价。
