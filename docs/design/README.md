## 对齐原则

正式 Web 以 v2.1 当前稿的布局、信息层级、交互密度、字号、间距和状态表达为表现层基线，但不能为了像原型而牺牲事实真实性。

当正式能力比静态稿更完整时，以真实产品语义为准，并同步更新当前原型。例如：

- 智能体必须区分“已检测”和“已启用采集”；
- 可观测能力展示采集方式和不完整原因；
- 工具错误示例如果当前接口没有逐次错误载荷，不使用演示文本冒充真实错误；
- 未报告的生命周期状态保持“未报告 / —”，不能按 0 展示；
- 健康接口没有端口字段时，顶部状态不得硬编码端口；
- Hook 属于具体 Source 的采集实现，不单独作为首次运行产品步骤；
- 未实现的 P1/P2 控件不进入当前 1.0 原型。

## 第二轮 1:1 追平结果

### 全局

- Header 使用正式 AgentLens Logo；主题切换统一 SVG；
- Header、Inspector、抽屉和 round-nav 不使用背景模糊毛玻璃；
- 正常界面文字下限统一为 12px；表格/列表主体按 13px 层级展示；
- 窄窗口只隐藏品牌文字，Logo 保留；
- 五个一级页面共用相同来源名称与来源色；
- Claude Code 不再以 `claude-code` 等内部 sourceId 暴露在用户界面。

### 五来源

内建来源统一为：

- Claude Code
- Codex
- Pi
- Hermes
- OpenCode

正式 Web 与当前原型共用对应浅色/暗色来源 Token。智能体快捷入口统一支持“＋ 管理”，未检测来源也可在管理入口中看见。

### 任务复盘

- 左右独立滚动、时间分组、相对时间、智能折叠和 turn-rail；
- 用户消息右侧、智能体消息左侧；
- Evidence（证据）默认可见；
- “显示原始记录”只补充来源原始事件与载荷；
- Inspector 为“详情 / 证据 / 原始数据”三页签；
- 工具类型统一 SVG；
- round-nav 使用不透明表面，不再有毛玻璃；
- 搜索防抖和筛选地址状态化。

### 工具分析

- 四项顶部指标、六列表格、真实比例条、“需要关注”和能力资产归因；
- 表格主体、标题和辅助层级与当前原型追平；
- 表头支持鼠标以及 Enter / Space 排序；
- 工具详情抽屉支持 Esc 关闭；
- Top 3 真实相关会话可直接进入任务复盘；
- 来源显示产品名称，不显示内部 sourceId。

### 使用洞察

- 当前原型与正式页统一到 1480px 内容宽度；
- 统计覆盖区、28px 指标、230px 趋势区、周期比较和响应式密度追平；
- 使用“智能体 / 技能 / MCP（模型上下文协议）”产品文案；
- 不显示无产品价值的 productId。

### 智能体概览

- 左侧 220px 来源列表 + 右侧单智能体详情；
- 来源栏间距、圆角项、资产数量、状态右置和窄屏横向列表追平；
- “已检测”和“采集中”分开表达；
- 高频资产真实比例条、技能生命周期真实漏斗；
- 可观测能力展示采集方式和原因；
- Hermes / OpenCode 纳入当前原型与正式来源体系。

### 资产备份

- 五来源名称和来源色统一；
- 当前原型与正式创建器都覆盖 10 类资产：技能、MCP、插件、扩展、钩子、记忆、规则、会话 / 历史、关键配置、其他；
- 创建器保持两列密度，窄屏切单列；
- 恢复预演支持 Esc 关闭；
- 当前 1.0 只做恢复预演，不直接写回任何智能体文件。

### 状态与首次运行

首次运行统一为：

1. 检测智能体；
2. 启用采集并确认运行；
3. 产生一条可复盘会话。

Hook 不再作为独立产品步骤。

## 自动防回退

- 正式 CSS 加载顺序：字体系统 → 设计令牌 → 最终配色系统 → v2.1 最终对齐层；
- 当前语义字号不得小于 12px；
- 正式 Web 与当前原型的浅色 / 暗色核心 Token 一致；
- Codex / Claude Code / Pi / Hermes / OpenCode 五来源 Token 一致；
- Header / round-nav 当前基线不使用背景模糊；
- 窄窗口保留 AgentLens Logo；
- 用户气泡和关键前景 / 背景对比度满足当前约束；
- 已退役表现层不得重新出现。

该检查已在 `.github/workflows/ci-1.0.yml` 的 Linux / Windows / macOS 三平台 `verify` 作业中执行，随后继续执行类型检查、测试和构建。
